# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security and privacy are foundational to Antiglaude Bridge. If you discover a security vulnerability:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the maintainer directly.
3. Include detailed steps to reproduce the vulnerability.
4. We will acknowledge receipt within 48 hours and work with you to provide a fix before public disclosure.

## Privacy & Local Execution

- Antiglaude Bridge runs strictly on `localhost` (`127.0.0.1`).
- No user tokens, request payloads, or system metadata are ever sent to third-party telemetric servers.
